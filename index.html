首次設定

這個 App 的資料會存在你自己的 Supabase（免費），別人看不到。照下面做一次就好：
  1. 到 supabase.com 註冊，建立一個新專案。
  2. 左側 SQL Editor → New query，貼上下方 SQL，按 Run。
  3. Authentication → Users → Add user → Create new user，填 email 和密碼，勾選 Auto Confirm User。
  4. 在專案中取得 Project URL，以及 Project Settings → API Keys 裡的 Publishable key，把兩個貼到下面。
不要貼 secret key 或資料庫密碼。
